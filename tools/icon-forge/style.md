# Стиль иконок мест

Этот файл — единый стиль-гайд для всех иконок набора. Его нужно передавать
модели вместе с эталонными SVG.

## Характер

- Фэнтезийная гравюра, тушь, картография.
- Контурный рисунок, без больших заливок.
- Силуэт важнее деталей.
- Иконка должна читаться в 24 px и не распирать круглый жетон 76 px.

## Технические правила

- `viewBox="0 0 24 24"`.
- Прозрачный фон, без круга, плашки, рамки и тени.
- Корневой SVG:
  `fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round"`.
- Только `stroke`; большой `fill` запрещён.
- Не использовать `black`, `white`, hex-цвета, `rgb()`, `hsl()`, градиенты.
- Не использовать `<style>`, `<script>`, `<image>`, `<text>`, `<foreignObject>`,
  внешние `href`/`xlink:href`, шрифты и растровые изображения.
- Внутренние отступы: 2–3 px от краёв.
- Одинаковая оптическая плотность у всех иконок набора.
- Внутренние линии — через `opacity=".4–.6"`, без второго цвета.
- Никаких букв, цифр и подписей внутри иконки.

## Что считается браком

- залитый силуэт;
- иконка на весь viewBox без отступов;
- слишком мелкие детали, исчезающие при 24 px;
- разная толщина линий у соседних иконок;
- декоративная рамка или фон;
- SVG, который нельзя вставить inline.

## Приёмка

1. Иконка читается при 24 px.
2. В жетоне 76 px остаётся воздух по краям.
3. Силуэт отличается от других иконок набора.
4. Цвет наследуется через `currentColor` в светлой и тёмной теме.
5. Нет больших `fill`-заливок.
