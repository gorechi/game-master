# Game Master

> **Vibe coding.** Проект собран в режиме вайб-кодинга: код, интерфейс и документация
> создавались ИИ по описанию задач, без классического проектирования и подробного
> ручного ревью. Архитектура и качество отдельных мест могут быть неровными, а баги —
> неожиданными. Перед реальной игрой сделайте резервную копию данных и проверьте
> нужные сценарии.

Game Master — офлайн-приложение для мастера D&D: сеттинги, игры, игроки, персонажи,
бестиарий, уникальные существа и карты. Работает без сервера и интернета, данные лежат
обычными JSON-файлами на диске пользователя.

## Возможности

- **Сеттинги** — отдельные миры со своими играми, персонажами, монстрами, картами
  и набором иконок. Выбираются при создании записи; общего «активного» сеттинга нет.
- **Игры** — подготовка и проведение партий: статусы, участники, монстры, карта,
  заметки и завершение с сохранением уникальных существ.
- **Экран проведения** — полноэкранная карта, переходы между связанными картами,
  заметки с автосохранением и запуск схватки.
- **Схватка** — инициатива, совпадения, очередь, текущий атакующий, HP монстров,
  кладбище и возврат в строй.
- **Игроки и персонажи** — люди за столом и карточки героев с портретами, классами,
  уровнями, расами и статусами.
- **Бестиарий и уникальные существа** — монстры с характеристиками, способностями
  и отдельная библиотека уникальных экземпляров.
- **Карты** — места, пути и выходы на другие карты; большое рабочее поле редактора
  с масштабом и перетаскиванием.
- **Оформление** — тёмная и светлая темы; все модальные окна, подтверждения и списки
  собственные, без системных диалогов и нативных `<select>`.

## Стек

- **Electron** — десктопная оболочка для Windows и macOS.
- **React + TypeScript** — интерфейс.
- **electron-vite / Vite** — сборка main, preload и renderer.
- **zod** — проверка данных из файлов и IPC.
- **electron-builder** — установщики NSIS, DMG и ZIP.
- **JSON-файлы** — прозрачное локальное хранение без нативных модулей.

## Запуск

Требуется Node.js 22.12+.

```bash
npm install
npm run dev        # Electron с горячей перезагрузкой
npm run dev:web    # только интерфейс в браузере: http://localhost:5180
npm run typecheck  # проверка типов
npm run build      # production-сборка в out/
```

Веб-предпросмотр хранит данные в `localStorage` браузера и нужен только для проверки
интерфейса. Реальные данные хранит десктопная версия. В dev-режиме данные лежат
отдельно от рабочей версии.

## Сборка установщиков

```bash
npm run dist:win   # Windows: NSIS x64 и arm64
npm run dist:mac   # macOS: DMG и ZIP x64/arm64, только на macOS
npm run pack       # распакованное приложение без установщика
```

Готовые файлы появляются в `release/<версия>/`. Сборки не подписаны: Windows может
показать предупреждение SmartScreen, macOS — Gatekeeper.

## Где лежат данные

- **Windows:** `%APPDATA%\Game Master\`
- **macOS:** `~/Library/Application Support/Game Master/`

Внутри — JSON-файлы игр, персонажей, монстров, карт, сеттингов и настроек. Папку можно
открыть кнопкой на странице «Настройки». Для переноса или бэкапа достаточно скопировать
эту папку.

## Структура проекта

```text
src/main/       главный процесс Electron: окно, IPC, хранение JSON
src/preload/    мост между main и renderer
src/renderer/   React-приложение
src/shared/     общие типы, схемы и доменные функции
tools/icon-forge/  инструмент для набора SVG-иконок мест
build/          иконка приложения и ресурсы сборки
scripts/        служебные скрипты
```

## Icon Forge

Отдельный локальный инструмент для набора SVG-иконок мест:

```bash
npm run icons:ui     # студия в браузере: http://localhost:5190
npm run icons:validate
npm run icons:preview
```

Генерация использует DeepSeek API. Ключ хранится только в локальном
`tools/icon-forge/.env` и не попадает в репозиторий.

## Стандартные иконки

Встроенный набор иконок для сеттинга D&D лежит в `preset-icons/`.
Он собирается в приложение командой:

```bash
npm run presets:build
npm run presets:check
```

Подробнее о ключах, версиях и правилах обновления — в `preset-icons/README.md`.
