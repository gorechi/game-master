# Локализация

Все пользовательские строки приложения лежат в `src/shared/i18n/locales/<язык>/`.
Код не содержит русского текста: он обращается к сообщениям локали.

## Как устроено

- `src/shared/i18n/index.ts` — реестр локалей, активная локаль, `fill`, `plural`, `formatDate`.
- `src/shared/i18n/types.ts` — общие типы (`PluralForms`, `MessageValues`).
- `src/shared/i18n/locales/ru/` — русская локаль, разбитая по разделам приложения.
- `src/renderer/src/i18n/LocaleProvider.tsx` — React-контекст: `useMessages()`, `useI18n()`, `useLocale()`.
- `src/main` и общий код вне React используют `m()` из `@shared/i18n`.

Базовая локаль — русская, сейчас также добавлена английская. Тип `Messages`
выводится из русской локали, поэтому новая локаль обязана содержать все те же
ключи: пропуск заметит TypeScript.

## Как добавить язык

1. Создай папку `src/shared/i18n/locales/<code>/` и повтори структуру разделов.
2. Собери объект в `index.ts` папки так же, как в русской локали.
3. Добавь локаль в реестр `locales` в `src/shared/i18n/index.ts`:
   ```ts
   import { en } from './locales/en'
   export const locales = { ru, en } as const
   ```
4. В локали укажи самоназвание языка в `app.languageName` (например, `English`).
   Оно автоматически появится в разделе «Настройки» → «Язык».
5. Проверь `npm run typecheck` и `npm run i18n:check`: TypeScript покажет
   недостающие ключи, а проверка — расхождения в плейсхолдерах и формах склонений.

Перезапуск приложения не нужен: выбор языка обновляет контекст, и интерфейс
перерисовывается сразу. Выбранный язык сохраняется в `settings.json`.

## Правила ключей и текста

- Ключи — только английский camelCase, без кириллицы.
- Ключ описывает место и смысл, а не просто слово: `maps.placeForm.save`,
  `games.combat.finish`.
- Одинаково звучащие слова в разных местах интерфейса — разные ключи. В другом
  языке они могут переводиться по-разному.
- Подстановки: `'Удалить игру «{name}»?'` + `fill(template, { name })`.
- Склонения: объект с категориями CLDR и обязательной формой `other`;
  для русского нужны `one`, `few`, `many`, `other`. Выбор формы — `plural(count, forms)`.
- Даты: `formatDate(iso, locale)` или `formatDate` из `useI18n()`.
- Не переводятся: пользовательские данные, технические идентификаторы, ключи
  хранилищ, URL, комментарии и логи разработчика.
- `main.realms.seedDescription` — описание стандартного сеттинга. Оно попадает
  в новые установки и автоматически обновляется при смене языка, если пользователь
  не изменил описание вручную.
