# Стандартные иконки

Этот каталог — источник встроенного набора иконок сеттинга **D&D**.
Иконки отсюда не используются приложением напрямую: при первом запуске из них
делаются обычные копии в сеттинге D&D.

## Как добавить или изменить иконку

1. Положи SVG в эту папку.
2. Добавь запись в `manifest.json`:
   - `key` — постоянный ключ, только строчные латинские буквы, цифры и дефис;
   - `title` — название для служебного списка;
   - `revision` — версия картинки;
   - `file` — имя SVG-файла.
3. Для новой иконки `revision` начинается с `1`.
4. Если картинка уже существующей иконки изменилась, увеличь её `revision`.
5. Подними `catalogVersion`, если меняется состав или картинки набора.
6. Запусти:

```bash
npm run presets:build
npm run presets:check
```

Первая команда проверяет SVG, собирает встроенный каталог и показывает, что
добавилось, обновилось или исчезло. Вторая проверяет, что собранный каталог
не отстал от `manifest.json`.

> Ключ иконки — постоянный. Если удалить иконку из набора, а потом вернуть её
> под тем же ключом, пользователи, которые её удалили, снова её не получат.
> Для действительно новой иконки лучше брать новый ключ.

## Что происходит в приложении

- при первом запуске все иконки набора попадают в D&D как обычные иконки;
- новая иконка в обновлении приложения добавляется один раз;
- изменённая иконка обновляется, только если пользователь её не перерисовывал;
- если пользователь изменил иконку, приложение оставляет его вариант;
- если пользователь удалил стандартную иконку, она не возвращается;
- иконки других сеттингов не затрагиваются.
